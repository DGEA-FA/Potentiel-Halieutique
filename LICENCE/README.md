# Licence Libre du Québec (LiLiQ)

## Historique

Le Centre de services partagés du Québec a développé au cours de l’année 2015 une licence adaptée aux besoins récents exprimés par divers organismes: la **Licence Libre du Québec (LiLiQ)**. Cette licence se présente en trois déclinaisons avec des clauses plus ou moins restrictives selon les besoins. La licence a été soumise à l’organisme [Open Source Initiative](http://opensource.org) pour validation et elle a été approuvée en janvier 2016. Pour connaître les fondements qui ont menés à la création de la licence, [cliquez ici](https://www.forge.gouv.qc.ca/licence/fondements/).

## Versions

- Permissive: [LiLiQ-P v1.1](https://www.forge.gouv.qc.ca/licence/liliq-p/)
- Réciprocité: [LiLiQ-R v1.1](https://www.forge.gouv.qc.ca/licence/liliq-r/)
- Réciprocité forte: [LiLiQ-R+ v1.1](https://www.forge.gouv.qc.ca/licence/liliq-r+/)

Nous avons également compilé une liste de [questions fréquemment posées (FAQ)](https://www.forge.gouv.qc.ca/licence/faq/) concernant la LiLiQ.

Enfin, voici d'autres liens d’intérêts concernant les licences de logiciels libres:

- [Secrétariat du Conseil du Trésor (Québec), Logiciels libres - Guide de référence](http://www.tresor.gouv.qc.ca/fileadmin/PDF/ressources_informationnelles/logiciels_libres/ll.pdf)

## Comment publier du code source sous LiLiQ ?

Vous devez inclure, à un endroit apparent, une copie de la forme de la LiLiQ applicable à votre projet. En règle générale, la licence se trouve dans un fichier nommé LICENCE ou LICENSE, et un fichier nommé LISEZMOI ou README fait référence au fichier de la licence.

Idéalement, un avis de copyright devrait se trouver dans chaque fichier et préciser que le logiciel est distribué selon les termes de la licence LiLiQ. Par exemple:

```
 /*
  * Copyright (c) 2022 Gouvernement du Québec
  *
  * SPDX-License-Identifier: LiLiQ-Rplus-1.1
  * License-Filename: LICENSES/LiLiQ-P11unicode.txt
  */
```

# Québec Free and Open Source Licence (LiLiQ)

## History

The Centre de services partagés du Québec has developped in 2015 a licence tailored for the public administration: the **Québec Free and Open Source Licence (LiLiQ)**. The licence was developed in three versions that differ in their level of reciprocity according to varying needs. This licence has been submitted to the [Open Source Initiative](http://opensource.org) for validation and has been approved in january 2016.

## Versions

- Permissive: [LiLiQ-P v1.1](https://www.forge.gouv.qc.ca/licence/en/liliq-p/)
- Reciprocity: [LiLiQ-R v1.1](https://www.forge.gouv.qc.ca/licence/en/liliq-r/)
- Strong reciprocity: [LiLiQ-R+ v1.1](https://www.forge.gouv.qc.ca/licence/en/liliq-r+/)

Finally, here's a list of [frequently asked questions (FAQs)](https://www.forge.gouv.qc.ca/licence/en/faq/) about the LiLiQ.

## How to publish source code under LiLiQ ?

A copy of the LiLiQ version that applies to your project must be included in a conspicuous location. In general, the licence is included in a file named LICENCE or LICENSE, and a file named LISEZMOI or README refers to the licence file.

Ideally, a copyright notice should be included in each file and should specify that the software is distributed under the terms of the LiLiQ licence. For example:

```
 /*
  * Copyright (c) 2022 Gouvernement du Québec
  *
  * SPDX-License-Identifier: LiLiQ-Rplus-1.1
  * License-Filename: LICENSES/LiLiQ-P11unicode.txt
  */
```
